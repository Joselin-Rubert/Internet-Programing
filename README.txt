INTERNET PROGRAMMING - 13 EXERCISES

Each exercise is kept in a separate folder with the files required for that topic.

01 - Ticket Reservation System
02 - Online Shopping using Advanced HTML5
03 - CSS Styles and Selectors on Online Shopping
04 - Job Portal Registration with JavaScript Validation
05 - Online Examination using HTML Form and Java Servlet
06 - Three-Tier Ticket Booking using Java Servlet
07 - Servlet Session Tracking
08 - JSP User Registration Display
09 - JSP + JDBC Online Order
10 - PHP E-Learning Registration + Server-Side Validation
11 - PHP + MySQL Online Order
12 - PHP Reading XML File
13 - XML + AJAX Asynchronous Interaction

Notes:
- Exercises 05-09 require a Java Servlet/JSP server such as Apache Tomcat and the appropriate Jakarta/Java libraries.
- Exercises 09 and 11 require MySQL. See database.sql.
- Exercises 10-12 require PHP/XAMPP.
- Exercise 13 is best run through a local web server because browsers may block AJAX file:// requests.
